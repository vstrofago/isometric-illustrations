Ten lines to a figure

Place objects in world units, let the engine sort, frame and animate them.

<div id="app"></div>
<script src="dist/iso.js"></script>
<script>
const s = Iso.scene('#app', { figure: { index: 'Fig. 1', title: 'Hello' } });
s.platform({ size: [160, 120] });
s.laptop({ at: [-10, 0, 0] });
s.card({ id: 'card', at: [44, 24, 0] });
s.float('card', { amp: 4 });
s.assemble();
</script>

What is inside

No dependencies at runtime. 35 KB gzipped.

  • Primitives — rounded boxes with chamfers, prisms, cylinders, cones, tubes, spheres, panels, hulls, text on planes, connectors, ribbons.
  • Depth — topological sorting by separating axes; moving objects re-sort every frame.
  • Motion — timelines, tweens, paths, float, travel, orbit, pulse, blink, spin, assemble, draw-on, typewriter.
  • Prefabs — 28 objects: devices, scenery, buildings, diagram blocks, a CRT desk computer.
  • Themes — dark, light, paper, blueprint, terminal; materials lit, glass, screen, ghost, tint.
  • Export — SVG, PNG, MP4, GIF, WebM, self-contained HTML; deterministic frames.
